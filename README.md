# 🎮 Песочница — Симулятор Жизни 3D

Открытый 3D-мир в стиле GTA для телефона и ПК. Зарабатывай, взрослей, дерись, строй отношения и заходи в VR-салон с тремя вселенными.

## 🎯 Возможности

- 🌆 **3D-город** с зданиями, дорогами и жителями
- 👤 **Реалистичные люди** — тело, руки, ноги, лицо, глаза, нос, рот
- 🥊 **Драка** — бей NPC, побеждай и забирай их деньги
- 💖 **Отношения** — знакомься, делай комплименты, приглашай на свидания и целуйся
- 🥽 **VR-Салон** с тремя вселенными:
  - 🎪 **Удивительный цифровой цирк** (Помни, Джингл)
  - 🟩 **Майнкрафт** (ломай и строй блоки)
  - 🟥 **Роблокс** (мини-игры: Natural Disaster, Adopt Me, Tower of Hell)
- 📱 **Телефон** с приложениями
- 💼 **Работа** — 3 подработки
- ⚡ **Энергия**, 💰 **деньги**, 🎂 **взросление**

## 🕹️ Управление

- **Джойстик** внизу слева (на телефоне)
- **WASD / стрелки** (на ПК)
- **Кнопки справа**: Работа, VR-Салон, Телефон
- **Кнопка действия** (появляется рядом с NPC): Ударить или Заговорить
- **Кнопка возврата** (сверху слева): Вернуться в город из VR

## 🛠️ Технологии

- **Three.js** — 3D-движок
- **Чистый JavaScript** (ES Modules)
- **Web Audio API** — синтез звуков (не нужны MP3)
- **Canvas API** — генерация текстур (не нужны PNG)

## 📂 Структура

Вся игра находится в **одном файле** `index.html` — это сделано специально, чтобы игра запускалась на GitHub Pages с телефона без ошибок с путями к файлам.
